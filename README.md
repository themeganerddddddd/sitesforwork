# MCEDC — Life & Quantum Sciences Site Explorer

An interactive, map-first site-selection website for Montgomery County, Maryland.

### What's included
- Six development sites: Belward Campus, Institute for Health Computing, COMSAT, Viva White Oak, Traville Gateway, and Pinkney Innovation Complex (PIC MC).
- Research and workforce anchors (NIH, FDA, NIST, UMD, and other regional institutions).
- Clickable site profiles showing on-the-ground development conditions, R&D opportunities, entitlements/readiness, and utility information.
- Toggleable 25-mile straight-line radius centered on Belward with SOC categories proposed for workforce analysis.
- MCEDC-inspired FY27 brand palette and typography, responsive layout.

### Deploy on Vercel
1. Visit https://vercel.com/new and select the **WestTech** team.
2. Import `themeganerddddddd/sitesforwork`.
3. Choose project name `sitesforwork`. The **Root Directory** should remain `./`.
4. Framework preset **Other** and no build command or environment variables.
5. Click **Deploy**.

The single-page website is at `index.html`. Leaflet, map tiles and Google Fonts load from external CDNs.

### Data caveats
Site markers are approximate. Information reflects a preliminary November 2026 assessment, not verified current parcel conditions or a utility-provider capacity commitment. The 25-mile radius indicates geography and relevant occupational groups; it is **not** a measured count of workers inside the radius. Validate details before external prospect use.
